# Авто Клиника — Краснодар

Статический сайт-визитка автосервиса. Для локального просмотра запустите сервер из корня репозитория:

```sh
python3 -m http.server 8000
```

Откройте <http://localhost:8000>.

Сайт можно опубликовать через GitHub Pages из корня репозитория.

Форма записи на сайте демонстрационная: отправка заявок пока не подключена.
